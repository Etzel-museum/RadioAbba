# הרדיو של אבא

אפליקציית אנדרואיד טבעית (לא אתר, לא PWA) לשמיעת רדיו אינטרנט בלי פרסומות
של האפליקציה עצמה. כפתורים ענקיים, בלי הגדרות, בלי כלום לגעת בו חוץ מלבחור
תחנה ולעצור.

## איך זה בנוי

- **Kotlin + Media3 ExoPlayer** (לא WebView) — כך יש שליטה אמיתית על
  buffering, reconnection ורקע, בדיוק כמו אפליקציות רדיו מקצועיות.
- **PlaybackService** (`app/src/main/java/com/davidlevi/radioabba/PlaybackService.kt`)
  רץ כ‑foreground service עם MediaSession, כך שהשמעה ממשיכה גם כשהמסך כבוי
  או כשעוברים אפליקציות.
- **StationRepository** (`Station.kt`) שולף בכל הפעלה רשימת תחנות מ‑
  `stations.json` בריפו הזה (raw.githubusercontent.com) עם timeout קצר,
  ונופל בחזרה לרשימה המובנית אם אין רשת/הקישור לא זמין. **זה מה שמאפשר
  לתקן כתובת שידור שנשברה בלי שאבא יצטרך להתקין עדכון** — פשוט עורכים
  את stations.json ודוחפים ל‑main.
- אין הרשאות מיותרות, אין מסכי הגדרות, אין התחברות.

## מה שמונע ניתוקים ועיכובים (מבוסס על מה שאפליקציות רדיו נפוצות עושות)

1. **Foreground service קבוע + WAKE_MODE_NETWORK** — מחזיק CPU + Wi‑Fi ערים
   בזמן ניגון כדי ש‑Android לא "יקפיא" את הזרם כשהמסך כבוי (בדיוק כמו
   TuneIn / Pocket Casts / BBC Sounds).
2. **באפרים גדולים לשידור חי** (DefaultLoadControl: עד 50 שניות buffer) —
   סופג פערי רשת קצרים בלי לעצור בכלל, במקום לנסות לנגן בלי מרווח בטחון.
3. **התחברות מחדש אוטומטית עם backoff** — בכל שגיאת נגן, השירות מנסה שוב
   אחרי 2/4/8/15/30 שניות (ולא מציף את השרת בבקשות), עד שהחיבור חוזר.
4. **מאזין לרשת (ConnectivityManager)** — ברגע שהאינטרנט חוזר (וויפי/סלולרי),
   מנסה להתחבר **מיד**, בלי לחכות ל‑backoff.
5. **מספר כתובות שידור לתחנה** (`urls` ברשימה) — אחרי 3 כשלונות רצופים
   בכתובת אחת, עובר אוטומטית לכתובת מראה חלופית לאותה תחנה, אם הוגדרה.
6. **Audio focus / becoming-noisy מטופלים ע"י ExoPlayer** — משתיק/עוצר נכון
   כשמתקשרים או מנתקים אוזניות, כדי שלא ינגן "מעל" שיחה.

## שימוש באינטרנט

עובד גם ב‑WiFi וגם בסלולרי (חבילת גלישה). שידור MP3 באיכות רגילה צורך בערך
**40–70MB לשעה** (כ־1MB לדקה בערך). זה משתנה מעט בין תחנה לתחנה.

## בנייה ל‑APK (GitHub Actions, ללא מחשב עם Android Studio)

1. יוצרים ריפו ציבורי (או פרטי) ב‑GitHub, למשל `RadioAbba`.
2. מעדכנים את `REMOTE_CONFIG_URL` בקובץ `Station.kt` עם שם המשתמש האמיתי
   ב‑GitHub (יש שם placeholder ברור: `REPLACE_WITH_GITHUB_USERNAME`).
3. דוחפים (`git push`) לענף `main`.
4. GitHub Actions (`.github/workflows/build-apk.yml`) בונה APK אוטומטית
   ומפרסם אותו כ‑Release בשם **latest** — קישור קבוע להורדה, גם לעדכונים
   עתידיים (למרות שברוב המקרים לא יהיה צריך לעדכן, כי stations.json
   מתעדכן מרחוק בלי APK חדש).
5. פותחים את הקישור מהטלפון של אבא (כרום), מורידים את ה‑APK, מאשרים
   "התקנה ממקורות לא ידועים" פעם אחת, ומתקינים.

## מגבלות ידועות

- זה לא אפליקציה מחנות Google Play (כדי לא לשלם/לעבור תהליך פרסום),
  אז ההתקנה היא APK ישיר — צריך אישור חד־פעמי בטלפון.
- כתובות שידור יכולות להשתנות מצד התחנות עצמן; אם תחנה תפסיק לעבוד
  לגמרי (גם המראה החלופית, אם יש), מעדכנים את stations.json בריפו.
